Placeholders you can use

Type any of these in your template (including inside the letter number) and the system fills them automatically on download:

  • {{FINANCIAL_YEAR}} – current financial year (April–March), e.g. 2026-27. Use it in the letter number so the year is always current: Rc.No. 1234/{{FINANCIAL_YEAR}}
  • {{NAME_OF_WORK}}, {{AGENCY_NAME}}, {{AGREEMENT_REF}}
  • {{AMOUNT}}, {{AMOUNT_IN_WORDS}}, {{MB_DETAILS}}

The date token dd.mm.yyyy is also replaced with the current month/year.
